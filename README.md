# Remanso Piscinas — proyecto conceptual

Landing de demostración de Tereré Estudio para una fábrica de piscinas de fibra de vidrio.
**Marca, datos e imágenes ficticios.** La página tiene `noindex` hasta que se publique en el portfolio.

- `sitio/` — sitio estático que publica Netlify (`netlify.toml`).
- `herramientas/build.py` — genera los HTML (modelos, textos, WhatsApp).
- `herramientas/ilustraciones.py` — dibuja las ilustraciones en WebP.
- `herramientas/logo.py` — genera el logotipo tipográfico en SVG.

Pendiente: número de WhatsApp de Tereré Estudio en `WA_NUM` (build.py) y email de seguridad en `sitio/.well-known/security.txt`.
